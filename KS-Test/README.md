## Основные функции
- Поиск городов через API сервис погоды
- Отображение температуры, местного времени и иконки погоды
- Сохранение списка городов между запусками
- Анимация удаления ячеек свайпом влево
- Обработка сетевых ошибок и дубликатов городов

## Реализация ТЗ

### Анимации
- **Удаление ячеек**: При свайпе влево ячейка плавно смещается за пределы экрана с использованием `UIView.animate` и удаляет за собой весь прогноз погоды на город
- **Обновление интерфейса**: Плавное появление новых городов через `UITableView` анимации

### Многопоточность
- **Сетевые запросы**: Выполняются в фоновом потоке через `URLSession.shared.dataTask`
- **Обновление UI**: Все изменения интерфейса выполняются в главном потоке через `DispatchQueue.main.async`
- **Параллельная загрузка**: Одновременная обработка нескольких запросов при запуске приложения

### Парсинг данных
- **Модели данных**: Использование `Codable` для декодирования JSON-ответа API
